木漏れ日こもれび

Komorebi Lite

こもれび らいと

同じ企画の軽量版でございます。普通のプレイヤーが実際に使うところだけを残しました。導入 → Java を選ぶ → バージョンを入れる → 起動。道は短く。

「Komorebi」は「木漏れ日」、枝葉のあいだから漏れてくる日の光のことですわ。

端書き

この頁は軽量版のお話でございます。同じ企画に版が二つございまして、完全版は Prism Launcher の構造をそのまま受け継いだ、機能の揃ったほう。モデパックの界隈まで手を伸ばせます。軽量版は、普通のプレイヤーが実際に使う一本道だけを残したほうでございます。リポジトリも、データの置き場所も、配布物も別々ですの。ですから二つは互いに干渉いたしませんし、片方がもう片方の代わりになることもございません。

軽量版のコードは独立した実装でございます。アカウントの認証も、バージョンの導入も、起動引数の組み立ても、公開されているプロトコルと形式に沿って書き直したもので、完全版や上流のソースは一切持ち込んでおりません。以下に書きますのは、0.2.4 が今この瞬間にしていることでございます。いつかするつもりのことは、一切書きません。だって「するつもり」を「した」と書いてしまうのは、史料を読む者がいちばん畏れることですもの。

壱

取捨残したものと、手放したもの

「取捨」と申しますのは、要は諦めが肝心ということでございますわ。手放したものを、なかったことにはいたしません。

  • 残したものローダーは五つ。NeoForge、Forge、Fabric、Quilt、それに OptiFine でございます。モデパックは CurseForge と Modrinth から検索して導入でき、導入の前に版を選んでいただきます。種類、公開日、大きさを並べ、既定では最新のリリース版に印が付きます。一覧は三十件ずつ、続きは頁を繰ってご覧じる。モデパックが指定したファイルは、そのファイルへ直接うかがいますので、古いファイルを指していても取りこぼしません。手元の .zip と .mrpack も承ります。作者が他の場所からの取得をお許しにならない MOD は、バージョンと配布頁を添えた一覧にいたします。落として hokora フォルダーへお入れになれば、版のほうへ自動で収まります。MOD からスクリーンショットまで面倒をみますし、サインインはデバイスコード、コマンドラインは二つ。
  • 手放したものLiteLoader。ATLauncher、FTB、Technic のモデパックと、MultiMC・PolyMC が書き出した圧縮ファイル。データパックの管理。認可コードと PKCE の流れ、外部の認証サーバー。ドライブを選べるデータの置き場所。三つの配置をもつ大正浪漫の外観でございます。
  • どちらも同じ簡体字中国語、English、日本語。コマンドラインの入口。ワールドとスクリーンショットの行き先。こちらへお移りになっても、覚え直しは要りませんわ。

二つはデータの置き場所も設定も共有いたしません。片方からもう片方へ移りますと、バージョンもアカウントも入れ直しでございます。ですから、どちらを使うか決めてからお入れくださいましね。

弐

二つの装い二通りの入れ方、お好きなものを一つ

同じプログラムに、装いが二つございます。どちらをお召しになっても、中身は一枚も減りませんの。同じ本文に装幀を二つ施したと申しましょうか。

  • 単体ファイル版まずは単衣のように軽いほうでございます。.exe ひとつ、口を開けば直ぐに立ち上がります。Qt を先に据える要も、ランタイムを揃える要もございません。USB メモリにお入れになって持ち歩かれても、恙なく参りますの。
  • ポータブル版こちらは旅支度の一箱。Qt のランタイムも、主題も、OptiFine の導入補助も、みな箱の底に収まってございます。解いた場所がそのまま置き場所になり、お立ちの際は箱ごとお提げになれば、機械のほうは綺麗なままでございますわ。

二つとも、バージョンもアカウントもワールドも、設定も、ランチャーの入っているフォルダにそのまま置きますの。史料の置き場所は一つに限ります——それゆえ、丸ごと写せばお引っ越しは済み、丸ごと消せばお片付けも済みますの。ただし、そのフォルダには書き込めなければなりませんの。Program Files のような場所では、開くのを止めてお断りいたしますわ。

参

引っ越し家ごとまるっとお移しください

お引っ越しの作法は一つだけ。荷は人についてまいりますの。

別のドライブへ移したいときも、作法は一つでございますの。ランチャーの入っているフォルダを丸ごとお移しくださいまし。バージョンもアカウントもワールドも設定も、みんなその中にございますから、新しい場所でもそのままでございますわ。ほかに何かいたすことはございませんの。

逆に、フォルダはそのままにランチャーだけを移しますと、人だけ参って荷が残ったということでございますの。ランチャーはそれを初めての起動と心得まして、画面は空っぽ。バージョンもアカウントもワールドも、みんな失せたかのように見えますわ。
