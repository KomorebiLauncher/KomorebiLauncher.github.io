Komorebi Launcher

こもれび ランチャー

Prism Launcher を元にした、オープンソースの Minecraft: Java Edition ランチャーでございます。中国大陸のネットワーク環境に合わせて、ダウンロードのミラー、Java の自動設定、OptiFine への対応を加えてございます。

「Komorebi」は「木漏れ日」、枝葉のあいだから漏れてくる日の光のことですわ。

壱

役目なにを解くか

国内のプレーヤーが汎用のランチャーを使いますと、よく突き当たるのは三つでございます。Mojang のダウンロード先が遅い、あるいはつながらない。Java のランタイムを自分で探さねばならない。MOD や整合包（モッドパック）の入手口が使いにくい。まあ、どれも頭の痛いお話ですこと。

よく聞く説明は「国内向けのランチャーに替えれば済む」というもの。あら、私はこの説明、嫌いではございませんのよ？　ただ、これ一本で語られるのが困るのですわ。三つはそれぞれ原因が違い、補う場所も違うのでございますから。

それで Komorebi Launcher ははじめ、上流の機能の骨組みには手を入れず、この三か所を別々に補っておりました。いまはその骨組みそのものも普請にかかっておりますの（第参節にて）。変わらないのは、ダウンロードがすべてプレーヤーご自身の機械と、公式の配信先（あるいはご自分でオンにしたミラー）とのあいだで済むようにしてある事。補う量が少ないのは構いません、補う場所を間違えるほうがずっと困りますもの。ここだけは、ぜったいに譲って差し上げませんでしたわ。

弐

機能いまできること

  • インスタンス管理

    インスタンスごとに .minecraft も設定もアイコンも独立。本体とローダーはコンポーネントとして付け外しでき、インポート・エクスポートも。

    MOD・リソースパック・シェーダー・データパック・ワールド・スクリーンショットは、そのままインスタンスの中で管理でき、Modrinth と CurseForge から探して入れられますわ。

    入れた MOD は、一つずつ配布元の版と照らして更新を確かめます。作者が第三者配布を許さない MOD を別の配信元から補うかは設定の中、既定はオフ。人の「否」を代わりに取りに行く真似は、いたしませんの。

  • ダウンロードミラー

    既定はオフですの。ゲーム本体・ライブラリ・リソースは Mojang の公式の配信先から落とします。

    設定 → API でオンにすると、三種類ごとにミラーと試す順番を決められます。失敗すれば順に次へ、公式はいつも最後の砦。詳しくは第肆節にて。

  • 爪哇Java の自動設定

    バージョンの要件に合わせて Java を選び、なければダウンロードいたします。清華大学オープンソースミラーの Adoptium ミラーを先に試しますの。

    許すバージョンの範囲を絞ることも、インスタンスのディレクトリに置いた Java を優先させることもできます。版は実際にプログラムを走らせて確かめますわ。ディレクトリ名なんて、誰でも書き換えられますもの。

  • メモリと JVM 引数の提案

    この機械のメモリと、このインスタンスの MOD の数から、ヒープの大きさを提案いたします。ガベージコレクションの引数もワンクリックで。

    入れるときは、ご自分で書かれた引数を残し、提案が上書きする同じ項目だけを差し替えますの。手で書いたものを丸ごと消すなんて、失礼でしょう？

  • 起動失敗の診断

    起動できなかったときはログを読み、メモリ不足、Metaspace 不足、Java の版と MOD の不一致、MOD の重複や依存の欠け、mixin の失敗、ドライバがウィンドウを開けない、テクスチャアトラスのあふれ——どれなのかを見分けて、直し方を差し上げます。

    日誌ログという子は、勝手に喋ってはくれませんの。喋らせる問いを先に用意しておくのが、こちらの仕事でございますわ。

  • サーバー一覧

    インスタンス内のサーバーを SLP で問い合わせ、接続人数・ゲームのバージョン・遅延を表示します。行に鼠マウスを留めれば、サーバー自身の挨拶文が読めますの。

    うふふ、密かに好きなのは、実はこの所でございますわ。

  • OptiFine

    バージョンのページから OptiFine を直接選んで導入できます。使うのは OptiFine 公式のインストーラーそのもの。ランチャーはダウンロードと、一時ディレクトリでの実行と、結果の回収だけを受け持ちます。

    パッチの仕組みは、どこも写しも作り直しもいたしません。そんな事は、淑女のいたす事ではございませんもの。

  • ローダーと整合包

    NeoForge、Forge、Fabric、Quilt、LiteLoader。上流と同じでございますわ。

    整合包は Modrinth、CurseForge、ATLauncher、FTB、Legacy FTB、Technic から。.mrpack や MultiMC・PolyMC の書き出した圧縮ファイルも取り込めますのよ。

  • 中国語の画面

    簡体字中国語は 100% 訳してございますわ。翻訳は本組織が自前で建てた静的な配信元（komorebilauncher.github.io/i18n/）から取り寄せ、起動時にハッシュを確かめてから読み込みますの。

    遊びたいゲームに中国語がなかったのが、私が翻訳を始めたきっかけ。ですからここだけは、絶対に手を抜きませんことよ♪

主幹の改築普請中

「普請」とは、もとはお寺で人々に呼びかけ、みなで堂を修める事でございます。ランチャーはいま骨組みを入れ替えている最中。出来上がるまで黙っているなんて、私の性に合いませんの。

この節に書く事はどれも主幹（main）にすでに取り込まれ、push のたびに CI が各プラットフォームでビルドしておりますけれど、まだ正式な版としては公開しておりません。0.2.2 をお使いの方には、まだ届いておりませんのよ。先にお試しになりたい方は、リポジトリの Actions のページから開発版のビルドをお取りくださいませ（GitHub へのログインが要ります。公開前の確認を経ておりませんので、壊れていたら、ぜひお知らせくださいね）。

  • 新しいコア層：

    上流のインスタンス・バージョン・起動のコードは画面と絡み合っていて、一か所直すと周りまで動かさねばなりませんの。そこで脇に launcher/komorebi/ という層を立てました。

    中ではウィジェットを一つも参照せず、素朴なデータだけを渡します。インスタンスの型録カタログ、マニフェストの継承の統合、起動コマンドラインの組み立て、Java の発見と選択（主バージョンが同じものを優先し、なければ要求より上でいちばん小さいもの）。どの規則も、ゲームにも Java にもネットワークにも頼らない単体テストで留めてございます。

  • すでにつないだ所：

    メインウィンドウのインスタンス一覧は、コア層から受け取るように替えました。ツールバー・献立メニュー・ショートカットは、これまでどおり選んだインスタンスに効きます。

    起動の道筋は、いまは開発用のプローブの中だけ。バニラのインスタンスなら、Java を選び、コマンドラインを組み、実際に起動するところまで参りましたわ。MOD ローダー入りはまだ読めません。読めないものは読めないと申します。画面の「起動」釦ボタンは、まだ元の道筋ですの。

  • 大正浪漫ロマンの装い：

    テーマをプログラムに組み込みました。明るい一揃いと、同じ絵から作った暗い一揃い。アイコンもランチャー自身の線の言葉で描き直し、墨色と月の色の二通りがございます。

    インスタンスは歌留多カードで並び、配置は既定の縦列、アイコンだけの細い列、操作を上へ移す横帯の三通りを、外観の設定から切り替えられます。背景画像、その見せ方、暗くする度合い、文字の色と縁取りも。

    「大正浪漫ロマン」と申しても、私の好きなものを一つずつ並べただけでございますけれど。うふふ。

  • 国内の整合包：

    HMCL と MCBBS 形式の整合包を取り込めますの。圧縮の中身はすべて元どおりにし、マニフェストが別途求めるファイル（MCBBS が CurseForge のファイル ID で示すもの、両形式の直リンク）は、お渡しする前に取り寄せます。

    SHA-1 が書いてあれば一つずつ確かめ、CurseForge がもう配っていないものは数えてお知らせします。審査を経ていない MOD は、CurseForge の整合包と同じく、並べてご確認を。行き先の外へ書こうとするパスは、すべてお断りいたしますわ。こっそり抜け出そうだなんて、いけませんわよ？

ダウンロードミラー鏡のしくみ

神話を読む者にとって「鏡」は重い字でございますのよ。八咫鏡は神そのものを映すための鏡ですもの。ここの鏡は、ただの硝子ガラスの鏡。ずっと素朴でございますわ。

ミラーがすることは、ひとつだけですの。ダウンロードの要求を、別のホストにある同じファイルへ差し替える事でございます。差し替え方は中身の種類ごとに決まっていて、Mojang 自身のホストにしか効きません。表にいたしますと、次のとおりでございます。

中身公式のホストミラー上の場所
バージョン一覧、クライアント jar、Java ランタイムpiston-meta / piston-data / launcher / launchermetaミラーのルート。ディレクトリ構成はそのまま
リソース（assets）resources.download.minecraft.netミラーの /assets 接頭辞
ライブラリとローダーのライブラリlibraries.minecraft.net などの maven ホスト順番つきの接頭辞の一覧を、一つずつ試します

ミラーは既定ではオフでございます。ミラーのほうが速いとは限りませんもの、勝手につけたりはいたしませんわ。お使いになるなら、設定 → API で切り替えてくださいませ。

内蔵のミラーは BMCLAPI と、教育網にある三つのミラーの maven ツリーでございます。

Java ランタイムの自動ダウンロードは別の道でして、清華大学オープンソースミラーの Adoptium ミラーを先に試します。ファイルは公式の SHA-256 と一致いたします。ただ、版の指定だけでファイル名を持たない api.adoptium.net の入口は、いまはまだ公式のままでございます。Modrinth や CurseForge などコンテンツ配信プラットフォームのホストは書き換えの対象外で、そのファイルはいつもそれぞれの公式の配信先から落とします。

ダウンロードはすべてメタデータに書かれたハッシュで確かめ、ミラーが違う中身を返せば検証失敗として扱います。素性の知れないものを、黙って受け取ったりはいたしませんの。

伍

アカウントとログイン名乗り

名乗りは、相手に信じてもらえて初めて意味を持つものでございます。以下の三つのアカウントの違いも、つまるところ「誰に名乗るか」ですのよ。

  • Microsoft アカウント：

    標準の OAuth 2.0（認可コード + PKCE と、デバイスコードの二通り。ログインの窓には両方ございます）を通り、公式の手順どおりに Xbox Live と Minecraft Services のトークンへ引き換え、アカウントのゲーム所有情報を読んでから、初めて起動をお出しします。

    Microsoft ログインに使う AppID は、本組織が登録し、2026-11-06 に Mojang の審査を通ったものでございます。プログラムに同梱されておりますので、入れてそのままログインしていただけますわ——ご自分でご申請なさる必要も、ご入力いただく必要もございませんの（派生ビルドを配布なさる場合は、ご自分で申請してくださいませね）。

    ログインのあとは、スキンのアップロードと外套マントの選択もできますの♪

  • オフラインアカウント：はっきりとローカルだけの身元でございます。プレーヤー名と UUID を手元で作るだけで、シングルプレイのワールドと、オフラインのプレーヤーを許すサーバーのために使います。Microsoft にも Realms にも、正規の認証を求めるサーバーにも認証いたしませんし、Microsoft や Minecraft のトークンは一つも受け取りません。オンラインのセッションが失敗したり切れたりしても、オフラインアカウントへ落ちることはございません。上流の Prism と同じく、Minecraft を所有する Microsoft アカウントを追加したあとでなければ作れません。起動とダウンロードは、ゲームを所有する Microsoft アカウントか、サードパーティ認証のアカウントを基準にいたします。この敷居は、わざと残してございますのよ。
  • サードパーティのアカウント：

    プレーヤーご自身が入力した認証サーバー（authlib-injector やその同類を動かしているサーバー）から、ゲームのトークンを受け取ります。アドレスには、サーバーがプレーヤーに渡している認証用のアドレスをそのまま入れてくださいませ。ランチャーがその下へ authserver/authenticate などのパスをつなぎますので、ご自分で補う必要はございませんし、補うべきでもございません。LittleSkin でしたら、案内されている https://littleskin.cn/api/yggdrasil のような形のアドレスを入れれば済みますわ。

    そのアカウントに複数のキャラクターがあるときは、最初のログインでどれにするかをお尋ねし、以後のログインはその選択どおりに求めます。トークンとキャラクター名は手元に保存いたします。サーバーがログインを断ったときは、サーバー自身が返した理由をそのままお見せします。

    それから、先に申し上げておきたい事がひとつございますの。ログインの資格情報は、この機械のアカウントファイルに平文で保存されます。このプロトコルが、アカウントとパスワードをトークンの引き換え時にしか受け付けないためでございます。インスタンスには authlib-injector のエージェントも要りますので、この種のアカウントで起動するときは、ランチャーがお尋ねしたうえで、インスタンスのコンポーネントとして入れて差し上げますわね。

For the Minecraft / Mojang app review team

Mojang のアプリ審査に宛てた英文のお手紙ですわ。開いてお読みくださいませ♪

What this is. Komorebi Launcher is a free, open-source Minecraft: Java Edition launcher for players in mainland China, a GPL-3.0 derivative of Prism Launcher. Everything is published in the repository linked above; there is no closed or obfuscated component, and no binaries are hosted anywhere else.

Current status. Our own application (client) ID was approved by Mojang Enforcement on 2026-11-06, confirmed by completing the full chain against the live services rather than by reading the notification, which is a batch email that names no application. This section documents the design that approval applies to.

The authentication chain we implement. Authorization code with PKCE, or the device code flow, against the Microsoft identity platform. The launcher requests Xbox access, obtains the Xbox Live and XSTS tokens, exchanges them at login_with_xbox, and checks the player's Java profile and Minecraft license. A Microsoft account counts toward launching or downloading only when that check passes. The tokens it is issued are kept in the launcher's local account file so the player does not sign in on every launch, and are sent only to the official Microsoft, Xbox Live and Minecraft Services endpoints. It does not use those endpoints to obtain game content for redistribution.

Why our own ID rather than an existing one. Upstream Prism Launcher's source states that a derivative work must ship its own credentials. Using another project's application ID would attribute our traffic to them and leave them unable to revoke it; we hold our own.

Load on your servers and CDN. API calls happen only when a player opens an account, browses, or launches. One game file download per version per player, from Mojang's own endpoints. No crawling, no bulk indexing, no background polling, and no redistribution of downloaded files from our side — the mirrors we ship rewrite Mojang-hosted file URLs only, and are used solely by the individual player who enables them. (Separately, the Java runtime downloader prefers a university mirror of Eclipse Adoptium, whose files match Adoptium's published SHA-256.)

Local profiles, stated plainly. Offline profiles are explicitly local identities for singleplayer worlds and for servers that allow offline players. They do not authenticate to Microsoft, Realms, or servers that require online accounts, and they receive no Microsoft or Minecraft token. One can be created only after an account that owns Minecraft has been added, and a failed or expired Microsoft sign-in never falls back to an offline profile. Separately, a player may point the launcher at a server operator's own authentication service; that service is added by the player, never contacts Microsoft, and is not part of the Microsoft sign-in path.

木漏れ日の光は、木のものではございません。木はただ、それを遮らなかっただけ。遊戯ゲームも、MOD も、アカウントも、みな他の方のものですもの。ですからこのランチャーも、その木のようでありたいと思っておりますの。風を少しよけて、あとは光を通すだけ。洋燈ランプを灯す必要もございませんの。木は光に何も語りませんから、こちらが問いを携えて木の下へ参りますの。

壊れているところがございましたら、リポジトリに issue を立てて教えてくださいませ。あそこは私たちの倶楽部クラブだと思ってくださいまし。だって私自身、壊れたものを見るとつい報告してしまう性分ですもの。報告をいただけるのは、うれしいばかりですわ。うふふ♪
