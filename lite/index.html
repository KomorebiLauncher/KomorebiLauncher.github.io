Komorebi Lite

こもれび らいと

同一个项目的轻量版：只做普通玩家真正用到的部分。装好 → 选 Java → 装版本 → 启动，路径短。

「Komorebi」写作「木漏れ日」，是从枝叶之间漏下来的日光ですわ。

端書き

这一页说的是轻量版ですわ。同一个项目有两个版本：完整版跟着 Prism Launcher 的结构走，功能齐、能碰整合包生态；轻量版只留下普通玩家真正会用到的那一条主线。两个仓库、两套数据目录、两个发行包，各走各的ですの——所以两只包互不打扰，也不能互相顶替。

轻量版的代码是独立实现的ですわ：账号登录、版本安装、启动参数构建，都是照公开协议与公开格式重写的，没有引入完整版或上游的源码。下面写的，都是 0.2.4 此刻实际在做的事；将来也许要做的事，我一概不写ですの。だって把「打算做」当成「做过了」，本就是读史料的人最怕的事ですもの。

壱

取捨留下来的，与让出去的

「取捨」说到底，就是舍得ですわ。让出去的部分，我不打算装作没有。

  • 留下来的加载器五个：NeoForge、Forge、Fabric、Quilt，外带 OptiFine；整合包从 CurseForge 与 Modrinth 搜来装，装之前先把版本挑明白：类型、发布时间、大小一并列出，默认落在最新的正式版上，列表一次三十个、往下翻还有更多，整合包钉在哪个文件上就照那个文件去取，钉的是旧文件也不会漏；本地的 .zip、.mrpack 也接得住；作者不许在别处下载的模组，会列成一张带版本号与页面链接的清单，下载好放进 hokora 文件夹就自动收进版本；模组到截图都归它管；微软登录走设备码；命令行两条ですわ。
  • 让出去的LiteLoader；ATLauncher、FTB、Technic 几家的整合包，与 MultiMC、PolyMC 导出的包；数据包管理；授权码加 PKCE 的流程与第三方验证服务器；可换盘的数据目录；三套布局的大正浪漫主题ですの。
  • 两边一样简体中文、English、日本語；命令行入口；存档与截图的去处ですわ。换过来，这几样不必重新学。

两边不共用数据目录，也不共用设置ですわ：从一只包换到另一只，版本与账户都得重新来一遍。所以请先想好要用哪一版，再动手装ね。

弐

二つの装い两种装法，挑一个就好

同一个程序，两种装束ですわ。挑哪一件，中身都不少一枚——好比同一部书，不过印了两种装帧ね。

  • 单文件版一件单衣似的轻装：一个 .exe，双击即开，机器上不必先请 Qt 进门，也不必先备下运行库；收进 U 盘带出门去，照样走得动ですの。
  • 便携包一只旅箱：Qt 的运行时、主题、OptiFine 安装助手都收在箱底，解在哪儿便在哪儿落脚；起身时把箱子一并提走，机器上仍旧干干净净ですわ。

两种都把版本、账户、存档、设置放在启动器所在的那个文件夹里ですの——史料的归处只该有一处，搬起来才不会散。整个文件夹拷走，就等于把家一起搬走；整个文件夹删掉，也就等于卸干净了ですわ。只是那个文件夹得能写——Program Files 这种要管理员才写得动的地方，它宁可不开，也要先把话说清楚ね。

参

引っ越し要搬家，就整个家一起搬

搬家的规矩只有一条：东西要跟着人走ですわ。

想换到别的盘，办法也只有一条ですの：把启动器所在的那个文件夹整个搬过去ですわ。版本、账户、存档、设置都在里面，搬到了新地方，它们原样就在，不必再做别的什么。

反过来，只把启动器挪走、文件夹留在原地，那就是只带了人、没带行李ですの：它会把这一次当成第一次启动，界面空空如也，看着就像版本、账户、存档全丢了一样ですわ。
